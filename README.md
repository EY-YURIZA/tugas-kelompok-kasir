Tugas Kasir Toko Kelontong

TUGAS KELOMPOK :
- Muhammad Miftahul Ulum
- Aditya Ramadhan Khiang

Tugas ini berisi kasir toko kelontong  untuk menghitung total uang yang harus dibayar pembeli setelah dipotong diskon. 

contoh perhitungannya:
- Kalo belanjanya nyentuh Rp100.000 dan dia bukan member, dapet diskon 10%.
- Kalo belanjanya nyentuh Rp100.000 dan dia itu member, diskonnya jadi 15%.
- Maksimal potongan harganya dibatasin mentok di Rp25.000 aja.

 langkah perhitungannya kita pisah jadi 3 fungsi:

1. Fungsi hitungPersenDiskon
Fungsi ini buat ngecek pembeli dapet diskon berapa persen. Pengecekannya dilihat dari total belanja sama status membernya (true atau false).

2. Fungsi hitungPotongan
Persenan diskon tadi diubah jadi nominal uang di sini. Sekalian kita kasih batesan, kalo uang potongannya hitungannya lebih dari 25rb, tetep kita hitung 25rb aja.

3. Fungsi hitungTotalBayar
Ini tahap akhirnya, tugasnya tinggal ngurangin total belanja awal sama uang potongan diskon tadi. Hasilnya jadi total uang bersih yang harus dibayar pembeli.
